# Selected UI

The approved combination is the compact dark top navigation with a blue Now Playing label, plus the original wmp-svg dark controls and curved tray. The visualizer and local media import are integrated with the existing player.

The original wmplayer.css from wmp-svg revision 84df38f3cebcc0d6d34547b60afd1beb5dbec3d7 is preserved as a stylesheet prefix. Integration styles follow the App integration only marker. Existing button and tray SVG resources are unchanged.

No WMPotify bitmap skin, custom chrome-dark.svg shell, backup, private media or reference experiment is included in this repository.
