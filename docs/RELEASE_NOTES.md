# v0.1.0 release notes draft

Status: unpublished. Publish only after the licensing and release checks are complete.

Milkdrop-Player is a browser-local audio/video player with WMP-inspired controls and Butterchurn audio visuals.

## Included

- Local media import and playlist controls.
- 100 bundled visualization presets.
- Fullscreen visualization with responsive canvas sizing.
- Pause/visibility-aware rendering and media/dependency error messages.
- Locally bundled visualizer dependencies for downloaded offline use.

## Running

Download and extract the complete player archive, then open `index.html` in a supported desktop browser. Keep all neighboring files and the `vendor/` folder. No package install is required for playback.

## Known limits

Codec support depends on the browser and OS. The interface is currently Simplified Chinese. Playlists reset on refresh. Real mobile devices, Firefox and Safari have not yet been verified. This is an independent project, with third-party rights described in THIRD_PARTY_NOTICES.md.
